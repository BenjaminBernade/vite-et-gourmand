# Validation des données

## Formulaires

Les formulaires de l'application permettent notamment :

- la création de compte ;
- la connexion ;
- la création de menus ;
- le passage de commande.

Les données saisies doivent être contrôlées avant leur traitement.

## Contrôles appliqués

Les contrôles portent notamment sur :

- la présence des champs obligatoires ;
- le format de l'adresse e-mail ;
- la longueur minimale du mot de passe ;
- le type des valeurs numériques ;
- la cohérence des quantités commandées.

## Objectif

La validation des données permet de limiter :

- les erreurs utilisateur ;
- les données incohérentes ;
- les risques d'injection ;
- les comportements non prévus de l'application.

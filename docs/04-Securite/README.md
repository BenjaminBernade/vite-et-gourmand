# Sécurité de l'application

Ce dossier présente les mesures de sécurité mises en place dans l'application **Vite & Gourmand**.

Les principaux axes traités sont :

- authentification ;
- protection des mots de passe ;
- contrôle des rôles ;
- validation des données ;
- sécurisation des accès à la base de données ;
- bonnes pratiques générales.

L'objectif est de limiter les risques courants liés aux applications web, notamment les injections, les accès non autorisés et la mauvaise gestion des informations sensibles.

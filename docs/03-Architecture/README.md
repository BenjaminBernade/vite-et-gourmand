# Architecture de l'application

Ce dossier présente les choix d'architecture réalisés pour le développement de l'application **Vite & Gourmand**.

## Contenu

- Choix techniques
- Structure du projet
- Architecture des données
- Séparation des responsabilités

L'objectif est de présenter une architecture claire, maintenable et adaptée au développement d'une application web moderne avec Next.js.

# Déploiement avec Vercel

## Présentation

L'application est prévue pour être déployée sur la plateforme Vercel.

Cette solution est particulièrement adaptée aux projets développés avec Next.js.

## Déploiement

Le dépôt GitHub est connecté à Vercel.

Chaque nouveau commit sur la branche principale déclenche automatiquement un nouveau déploiement.

## Variables d'environnement

Les variables sensibles sont configurées dans l'interface Vercel.

Exemples :

- DATABASE_URL
- NEXTAUTH_SECRET
- NEXTAUTH_URL

## Avantages

- déploiement automatique ;
- certificat HTTPS ;
- performances optimisées ;
- intégration native avec Next.js.

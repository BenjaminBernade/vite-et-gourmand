# Conteneurisation avec Docker

## Objectif

Le projet peut être conteneurisé afin de faciliter son installation sur différents environnements.

L'utilisation de Docker permet de garantir un environnement identique entre le développement et la production.

## Conteneurs prévus

- Application Next.js
- PostgreSQL
- MongoDB

## Fichiers associés

Le projet prévoit les fichiers suivants :

- Dockerfile
- docker-compose.yml

## Avantages

- installation simplifiée ;
- reproductibilité ;
- isolation des services ;
- facilité de déploiement.

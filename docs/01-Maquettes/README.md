# Maquettes de l'application

## Présentation

Les maquettes de l'application **Vite & Gourmand** ont été réalisées avec **Figma** dans le cadre de la phase de conception du projet.

Elles permettent de définir l'organisation générale des écrans, les parcours utilisateurs ainsi que les principaux éléments de l'interface avant le développement.

Les maquettes présentées sont volontairement fidèles à l'application développée afin d'assurer une cohérence entre la conception et la réalisation.

---

## Outil utilisé

- Figma

---

## Écrans réalisés

Les maquettes couvrent les principaux parcours de l'application :

1. Accueil
2. Liste des menus
3. Détail d'un menu
4. Connexion
5. Tableau de bord utilisateur
6. Administration

## Objectif

Ces maquettes ont servi de support à la conception de l'interface utilisateur.

Elles présentent la structure générale des différentes pages, les principaux composants graphiques ainsi que les interactions prévues pour les utilisateurs et les administrateurs.

Le développement de l'application a ensuite été réalisé à partir de ces maquettes tout en conservant leur organisation générale.
